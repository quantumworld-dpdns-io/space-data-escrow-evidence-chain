# ADR-004: Observability and Evaluation

- Status: Accepted
- Date: 2026-05-19
- Context: Need operational telemetry plus AI-output evaluation.
- Decision: Plan OpenTelemetry for system telemetry and Weave for AI-eval workflows.
- Consequences: Dual observability layers for runtime and AI quality.
- Alternatives Considered: Single-platform-only tracing.
